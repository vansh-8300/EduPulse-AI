Layer 1: Data Sources & Ingestion Points

Raw Student Academic, Behavioral & Engagement Ingestion

Captures multi-dimensional student performance and interaction signals from campus administrative and digital learning environments.

Technical Inputs:

Student course records, LMS portal activity logs, lecture attendance scanner logs, assignment submission timestamps, and student wellness self-reports.

Implementation Artifacts & Code:

Files: data/students_1200.csv & generate_data.py

Key Functions: generate_student_dataset(), load_student_data()

Data Outputs & Destination:

Tabular raw student profile records containing 8 core features plus demographic identifiers (Student ID, Name, Major, Grade Level, Tuition Status).

Engineering Notes:

Project uses 1,200 synthetic student records with correlated Gaussian distributions for hackathon demonstration. Future roadmap includes LMS LTI integration (Canvas/Blackboard).

EXECUTION CYCLE

End-to-End Operational Workflow

A systematic 6-step data lifecycle tracing how raw educational records flow through validation, algorithmic inference, visual analytics, and targeted advisor intervention.

1
Ingestion

Collect student records

Campus information systems capture multi-dimensional student indicators: GPA, attendance rates, LMS digital engagement, assignment completions, study habits, and stress surveys.

data/students_1200.csv
2
Processing

Load and prepare student features

The ingestion pipeline verifies data integrity, applies range constraints, extracts the 8 model predictor columns, and caches cohort distributions in memory using Streamlit data caching.

src/data_loader.py → load_student_data()
3
Model Loading

Apply the trained ML model

Loads the serialized Scikit-Learn Random Forest model artifact (120 decision trees, depth 10) after cryptographically verifying its SHA-256 hash checksum for artifact integrity.

src/model_utils.py → load_model()
4
Inference

Estimate student risk and indicators

Executes predict() and predict_proba() to derive class probabilities (High, Medium, Low), computes the 0–100 Student Success Score, and benchmarks feature Z-scores against cohort means.

src/model_utils.py → predict_student_risk()
5
Analytics

Present insights through analytics

Renders interactive Plotly visual analytics in the Streamlit application: cohort KPIs, risk distribution bar charts, GPA vs Attendance scatters, and student search directories.

app.py → Plotly Theme & Cohort KPIs
6
Action

Generate recommendations & interventions

The recommendation engine matches specific metrics below threshold to prioritized recovery actions, and the What-If simulator enables advisors to test recovery parameter adjustments.

src/recommendations.py → generate_recommendations()

⚠️

Prototype Transparency & Synthetic Data Disclosure

The EduPulse AI machine learning model and demonstration analytics operate on 1,200 synthetic student records generated using NumPy Gaussian distributions and latent capability correlations (generate_data.py). The 90.0% evaluation accuracy reflects this controlled synthetic benchmark. These predictions demonstrate algorithmic feasibility and must not be interpreted as validated real-world institutional outcomes without formal institutional review and multi-cohort empirical validation.

EXECUTIVE SUMMARY

Architecture Summary

A concise architectural digest summarizing the responsibilities and technical roles of each core layer in EduPulse AI.

Layer 01

Input Layer

Ingests multi-dimensional academic performance, attendance logs, LMS digital activity, and well-being metrics from campus records into structured tabular schemas.

Layer 02

Processing Layer

Validates data integrity, enforces feature vector alignment, computes cohort-level benchmarks, and leverages in-memory caching for zero-latency retrieval.

Layer 03

ML Layer

Executes a balanced 120-tree Random Forest classifier with SHA-256 integrity verification, generating calibrated risk probabilities and Z-score indicator impact rankings.

Layer 04

Application Layer

Delivers an interactive Streamlit analytics portal featuring Plotly data visualizations, student drill-downs, search directories, and sensitivity scenario simulators.

Layer 05

Decision-Support

Translates predictive outputs into prioritized, actionable interventions and personalized recovery roadmaps that empower educators to proactively prevent student attrition.
